# Climate Analysis: Diurnal Temperature Range (DTR) Statistics (1981–2025)

This academic project demonstrates data cleaning, exploratory analysis, trend analysis, and visualization using Python[cite: 1]. The analysis was performed on a publicly available climate dataset[cite: 1].

## Project Overview
This repository evaluates the Diurnal Temperature Range (DTR) and average temperatures across five distinct ecological and climatic zones in Ghana (Coastal Zone, Forest Zone, Transition Zone, Guinea Savanna, and Sudan Savanna) from 1981 to 2025[cite: 1].

## Repository Structure
- `climate-dtr-analysis.ipynb`: The main Jupyter notebook containing the code and data analysis[cite: 1].
- `requirements.txt`: Python package dependencies.
- `README.md`: Project documentation.

## Key Findings
- **North-South Temperature Gradient:** Overall mean and maximum temperatures increase progressively as you move from the Coastal Zone to the Sudan Savanna[cite: 1].
- **Diurnal Range Expansion:** The Diurnal Temperature Range (DTR) expands significantly moving inland, with the lowest mean DTR in the Coastal Zone (2.35 °C) and the highest in the Sudan Savanna (9.39 °C)[cite: 1].
